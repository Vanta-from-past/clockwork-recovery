# clockwork-recovery

Если станция ещё отвечает, не меняй положение кассет наугад.

Я вынес эту копию за её пределы. Здесь правки хотя бы оставляют следы.

## С чего начать

Сверь контрольный ряд проекта с тем, что ты уже принял по радио. У неверного ряда тоже может быть аккуратная сумма. Совпадение подписи важнее надписи «исправлено».

Затем открой [паспорт механизма](docs/mechanism.md). Нужно восстановить пять кассет и сторону каждой из них. Измерения находятся в журнале стенда; надписи с ободков — в каталоге пластин.

Собирать или запускать программу не требуется. Все материалы читаются в браузере. История файлов и история проекта — часть архива. Скачать ZIP можно, но старые версии в обычный ZIP не входят.

Я не оставил здесь кнопку возвращения. Подтверждение принимает станция.
