# Паспорт М-08 / синхронизированная редакция

В кассете пять мест. Каждое занимает одна из пластин ASH, ECHO, IRIS, NOON, WREN. Повторять пластину нельзя.

Каждая пластина изменяет положение стрелки на круге из 26 делений: от 0 до 25. После 25 снова идёт 0; перед 0 — 25.

Пластину можно поставить лицом к наблюдателю (+) либо лицом к стеклу (-). Царапина на ободке задаёт величину `a`.

* Лицом к наблюдателю: из `a` вычитается `x`.
* Лицом к стеклу: к текущему положению `x` прибавляется `a`.

В обоих случаях результат приводится в диапазон 0–25 по кругу.

Например, для царапины 9 и входа 23 лицевая установка даёт 12, а обратная — 6.

| Пластина | Царапина a |
|---|---:|
| ASH | 3 |
| ECHO | 7 |
| IRIS | 11 |
| NOON | 17 |
| WREN | 23 |

## Чтение после восстановления

Сверь сборку со всеми сохранившимися измерениями. Потом читай надписи на пластинах в порядке мест 1–5. Надпись на пластине, повёрнутой к стеклу, читается с последнего символа к первому.

Раздели фрагменты пробелами. Это и будет контрольное сообщение для станции.
