# Оттиски ободков

Надписи сняты при одинаковом положении пластин — лицом к наблюдателю. Таблица отсортирована по имени пластины, а не по месту в механизме.

| Имя | Оттиск |
|---|---|
| ASH | THE |
| ECHO | NEPO |
| IRIS | PEEK |
| NOON | 145 |
| WREN | TIXE |

В исходном паспорте есть правило чтения оттиска после установки. Не разворачивай сам порядок кассет: сторона меняет только чтение отдельного фрагмента.
